# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Navidrome is a self-hosted music server: a Go backend (single binary with the React UI embedded) that serves Subsonic, Jellyfin-compatible, and native REST APIs.

## Commands

Run `make help` for the full target list. Go builds and tests need the tags `netgo,sqlite_fts5` (the Makefile adds them; pass them yourself when calling `go` directly).

- `make setup`: first-time setup (Go deps, `npm ci` in `ui/`, golangci-lint into `./bin`, git hooks).
- `make dev`: backend plus Vite UI with hot reload, on port 4533. `make server` runs only the backend (reflex restarts it on `.go` changes). `make stop` kills both.
- `make build`: builds the UI (`ui/build`), then the Go binary.
- `make test`: all Go tests. Narrow it with `make test PKG=./server/subsonic/...`.
- Single Go test: tests use Ginkgo/Gomega, so focus by spec name:
  `go test -tags netgo,sqlite_fts5 ./core/playlists -run TestPlaylists -ginkgo.focus "<spec description>"`
  (or `go tool ginkgo -tags netgo,sqlite_fts5 --focus "<spec description>" ./core/playlists`).
- `make test-race`, `make testall` (Go + ndpgen + i18n + JS), `make test-js` (Vitest in `ui/`).
- `make lint` (golangci-lint, config in `.golangci.yml`), `make lintall` (also Prettier check and ESLint for the UI).
- `make format`: Prettier for the UI, `goimports` for Go, `go mod tidy`. The pre-commit hook rejects Go files that aren't `goimports`-formatted, and pre-push runs `make pre-push` (`lintall` + `testall`).
- `make snapshots`: regenerate the Subsonic response snapshot tests (`server/subsonic/responses`) after changing response shapes.
- `make wire`: regenerate dependency injection (`cmd/wire_gen.go`) after changing constructors or provider sets.
- `make gen`: run `go generate` plus the OpenAPI codegen and plugin PDK/host-wrapper generation (`plugins/cmd/ndpgen`).
- `make migration-sql name=foo` / `make migration-go name=foo`: new goose migration in `db/migrations`.
- API v1 (OpenAPI): the spec lives in `api/openapi/`. Use `make api-lint`, `make api-gen` (bundle the spec and generate `server/apiv1/api_gen.go`), and `make api-diff` (fails on breaking changes against `origin/master`).

## Architecture

- **Entry and DI:** `main.go` calls the Cobra commands in `cmd/`. Components are wired with Google Wire: provider sets live in `cmd/wire_injectors.go` (and `Set` vars such as `core.Set`), and `cmd/wire_gen.go` is generated, so don't edit it by hand.
- **Config:** `conf/configuration.go` holds the `Options` struct, loaded via Viper from `navidrome.toml` and `ND_*` environment variables, and exposed as `conf.Server`.
- **Data layer:** `model/` defines domain types and repository interfaces, with `model.DataStore` as the entry point for all repositories. `persistence/` implements them on SQLite (using dbx and squirrel). `db/` opens the DB and runs goose migrations from `db/migrations` (both SQL and Go migrations, validated in CI).
- **Business logic:** `core/` holds services (artwork, playback/jukebox, transcoding/stream, scrobbler, lyrics, playlists, external metadata agents, sonic similarity, and so on). `adapters/` contains external integrations such as Last.fm and ListenBrainz.
- **Scanner:** `scanner/` imports the library in phases (`phase_1_folders` → `phase_2_missing_tracks` → `phase_3_refresh_albums` → `phase_4_playlists`), plus a filesystem watcher. See `scanner/README.md`.
- **HTTP:** `server/` sets up the chi router and middleware and mounts these APIs:
  - `server/subsonic`: Subsonic API, used by most third-party clients.
  - `server/nativeapi`: the REST API used by the web UI (react-admin).
  - `server/apiv1`: OpenAPI-generated API v1.
  - `server/jellyfin`: a subset of the Jellyfin API, disabled by default (see its README).
  - `server/public`: share links.
  - `server/events`: SSE broker for pushing events to the UI.
- **Plugins:** `plugins/` is a WebAssembly plugin system built on Extism. `manager*.go` loads and runs plugins. Plugins implement capabilities (`plugins/capabilities`), such as metadata agent, scrobbler, lyrics and sonic similarity, and call host services (`plugins/host`, `host_*.go`). PDKs in `plugins/pdk` are generated by `ndpgen`. See `plugins/README.md`.
- **UI:** `ui/` is React with react-admin and Material UI v4, built with Vite and tested with Vitest. Use the Node version in `.nvmrc`. The production build is embedded into the Go binary.
- **Tests:** each package has a `*_suite_test.go` Ginkgo bootstrap. Shared mocks (`tests.MockDataStore` and per-repo mocks) and fixtures live in `tests/`.

## Local fork notes

- **Vibrant theme family (in progress):** `ui/src/themes/vibrant.js` builds a Dark and a Light theme from each palette in `vibrantPalettes.js`; `vibrant.css.js` styles the audio player and `vibrant.test.js` checks palette contrast (WCAG AA). All four palettes are built: Ember, Aurora, Lagoon and Neon Pop. To add one, add a palette entry, a `<name>.js` theme file like `ember.js`, and register both themes in `themes/index.js`.
- **Other themes are hidden from the theme picker (temporary):** `isThemeInPicker` in `ui/src/themes/index.js` limits Personal → Theme to Vibrant themes, and `ui/src/personal/SelectTheme.jsx` also drops the "Auto" option. The hidden themes are still registered, so saved preferences, `DefaultTheme` and tests still use them. To restore them, make `isThemeInPicker` return true and restore the Auto choice in `SelectTheme.jsx`.

## Contribution conventions (from CONTRIBUTING.md)

- Commit format is `<type>(scope): <description>`, where type is one of `feat|fix|sec|docs|style|refactor|perf|test|build|revert|chore`. Sign off every commit (`git commit --signoff`, DCO).
- Prefer existing patterns and the smallest clear change. New dependencies, config options or abstractions need justification.
- PRs must state whether AI was used. An AI agent must never tick the personal-review or development-knowledge checkboxes in the PR template on the contributor's behalf.
